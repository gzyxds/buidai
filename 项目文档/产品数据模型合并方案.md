## 二、目标模型

### 2.1 数据形态

新建 `data/products/` 目录，按实体拆分文件：

```text
data/products/
├── index.ts        # 唯一入口（re-export）
├── entities.ts     # 实体自动收集（import.meta.glob）+ 查询工具
├── market.ts       # 市场视图派生层（marketApps/marketCategories）
├── demo.ts         # 演示视图派生层（demoCategories/状态工具）
├── types.ts        # Product 统一类型（三视图）
├── detail/         # 产品中心：三视图齐全的 12 个实体
├── market/         # 应用中心：16 个市场专属实体
└── demo/           # 演示中心：2 个演示专属实体
```

> 注：实体收集采用 import.meta.glob 自动注册（新增实体文件即注册），
> 按主视图分目录归类（detail/market/demo），替代初版的平铺 + 手工登记。

单一 `Product` 接口，含三个**可选视图**：

```ts
interface Product {
  /** 统一标识：slug（沿用 products.ts 的命名，向 demo 的 kebab 兼容） */
  slug: string
  /** 显示名（统一入口） */
  name: string
  /** 短描述（列表/卡片用） */
  description: string
  /** 图标名（i-xxx 格式） */
  icon?: string
  /** 封面图 */
  image?: string
  /** 标签 */
  tags?: string[]

  /** 视图 A：产品详情页（现 products.ts） */
  detail?: {
    seo: SeoData
    hero: HeroData
    featuresGrid: FeaturesGridData
    features: FeatureItem[]
    featureDetails: FeatureDetail[]
    cta: CtaData
  }

  /** 视图 B：应用市场（现 pluginData.ts） */
  market?: {
    category: string          // 市场分类
    originalPrice: number
    discountPrice: number
    date?: string
    link?: string
  }

  /** 视图 C：演示中心（现 demoProducts.ts） */
  demo?: {
    status: 'online' | 'beta' | 'coming'
    category: string          // 演示分类（独立系统/扩展应用）
    features: string[]
    platforms: DemoPlatform[] // 含演示账号信息
  }
}
```

### 2.2 消费方改造

| 消费方 | 读取方式 |
| --- | --- |
| `pages/product/[slug].vue` | `getProductBySlug(slug).detail` |
| `pages/plugin.vue` / `Market.vue` / `HeroSection.vue` / `FeatureCarousel.vue` | `products.filter(p => p.market)` 按分类/排序派生 |
| `pages/demo.vue` + demo 组件 | `products.filter(p => p.demo)` 按演示分类分组 |
| `getSitemapRoutes.ts` | `products.filter(p => p.detail).map(p => '/product/' + p.slug)` |

各页面**不动模板**，只改数据来源与字段访问路径（尽量保持派生后的对象形状与原接口一致，减少模板改动）。

## 四、冲突裁决规则（合并同一实体时）

同一实体在三处的字段冲突，按以下优先级裁决：

1. **文案（name/description）**：以 products.ts 的 detail 文案为准（它是公开 SEO 文案，最完整）；demo/market 的文案保留在各自视图（如果各视图需要不同的营销口吻，允许覆盖）
2. **图片**：demo 视图优先（demo 图通常更新）；detail 的 `demoImage` 保持独立
3. **图标**：demo/pluginData 的 icon 若缺失则回退到 detail 无图标的展示方式
4. **标签**：并集去重
5. **市场分类 vs 演示分类**：互相独立，各自视图字段
